# Custom Fortress 2

Custom Fortress 2 is a Team Fortress 2 Source Mod consisting a collection of changes that could end up in Live Team
Fortress 2, the goal is to try making as much stuff as possible less hardcoded, to give level designers and VScripters
more customization like custom map titles, kill icons, and so on.

This is also meant to be as a "Playground" build, demonstating how TF2 could function with community fixes and such, this is just for fun feel free to fork, or use
